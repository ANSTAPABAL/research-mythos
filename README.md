# Сжатые формы текстовых цепочек рассуждения

Исследовательский анализатор на Python/Streamlit для корпусного и лингвистического разбора наблюдаемых reasoning traces. Версия после рецензии: **v2.1.0**, расчёт 02.10.2026, seed 20261002. Основная конфигурация — `review_config.json`.

12 088 цепочек четырёх моделей по всем 3 022 общим вопросам, 43 задачи. Окна 128 токенов: 2 875 вопросов; 256: 1 668; 512: 576. До трёх полных исходных окон усредняются внутри цепочки. Одна единица парного сравнения — вопрос; иерархический bootstrap — задача → вопрос. Вопросные Wilcoxon/Holm приведены дополнительно и не учитывают кластерную зависимость.

На одних и тех же 2 875 вопросах в полных цепочках медиана zlib/UTF-8 у Claude выше DeepSeek (0,414 против 0,356); при одинаковой токенной длине — ниже (0,503 против 0,534). Медиана парной разности: −0,029799, 95% иерархический ДИ [−0,035582; −0,025463], ранговый эффект −0,867352. Это алгоритмическая регулярность текста; она не является оценкой человеческой понятности или скрытых вычислений.

## Запуск приложения с готовыми результатами

Python 3.11–3.12. Из корня репозитория:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-lock.txt
.venv\Scripts\python start_app.py
```

В Linux/macOS замените путь интерпретатора на `.venv/bin/python`. Приложение открывается на http://127.0.0.1:8501. Ключи провайдеров не нужны: работа ведётся с опубликованным корпусом. Экраны: обзор, исходная цепочка, сравнение моделей, полные локальные окна, разметка, внешние кейсы Mythos/Astra, статистические таблицы и выгрузка CSV.

## Воспроизведение

```powershell
.venv\Scripts\python reproduce.py
```

Команда скачивает закреплённый корпус и источники, выполняет аудит, анализ всех общих вопросов, оконные метрики и проверки устойчивости, восстанавливает записанную первичную разметку, строит рисунки, DOCX и запускает тесты. Около 1 GB исходных данных; полный пересчёт занимает несколько минут. `--offline` требует уже скачанный `data/raw` или локальный `data/interim/all_baselines.parquet`. Готовые сопоставимые тексты включены для просмотра в приложении; для независимого повторения отбора используйте закреплённый исходный корпус.

`run.py review_figures`, `run.py code_review_annotations`, `run.py build_article_review` восстанавливают отдельные артефакты. `python -m pytest tests -q` проверяет метрики, парный отбор, raw-окна и иерархический bootstrap. Проверки Word-вёрстки в `review_checks.py` дополнительно требуют локальных PDF-рендеров и первичных PDF; эти файлы не распространяются целиком. Самостоятельный повтор bootstrap по каноническому Parquet совпал для всех 48 основных сравнений; это проверка повторяемости, а не независимая содержательная валидация.

## Данные и разметка

- `outputs/review_v2/manifest.json`: состав, исключения коротких записей, ревизия и SHA конфигурации.
- `outputs/review_v2/fixed_window_metrics.parquet`: канонические признаки с сохранением точности. CSV — читаемые представления; перевод CSV обратно в числа может менять почти равные ранги.
- `outputs/review_v2/tables`: все парные эффекты, интервалы, медианы, дополнительные показатели и чувствительность.
- `outputs/review_v2/all_common_traces.parquet`: исходные сопоставимые записи из публичного корпуса, с вопросами и метаданными.
- `data/annotations/annotation_coded.csv`: 96 фрагментов, восемь бинарных категорий, точные основания и соседний контекст.
- `data/annotations/CODEBOOK.md`: правила, исключения и различие грамматического дополнения и расширения доказательства.
- `data/annotations/second_annotator_blind.csv`: без названий моделей, страт и первичных решений, для второго аннотатора.

**Разметка выполнена ИИ-ассистентом; независимого человека-аннотатора пока нет.** Согласие не рассчитано. Выборка обогащена символами и пунктуацией; её частоты нельзя считать распространённостью явлений в корпусе. Первичные решения записаны явно в `src/code_review_annotations.py`: этот файл не является классификатором и не воспроизводит человеческую экспертизу.

Mythos и Astra не входят в количественный корпус. Их опубликованные выдержки — внешние иллюстрации. У Astra отдельно обозначены отобранный raw CoT из AISI и экспериментально вызванное объяснение, не подтверждённое как дословная нативная скрытая цепочка.

## Источники, лицензии и границы

Корпус: [ameek/measuring_cot_monitorability_transcripts](https://huggingface.co/datasets/ameek/measuring_cot_monitorability_transcripts), ревизия `a7a8b25ae467db9d80d63e55ac053b48753b2d36`; Meek et al., [arXiv:2510.27378](https://arxiv.org/abs/2510.27378). Сохранены `data/raw/LICENSE` и исходный README, включая атрибуции BBH/MMLU/GPQA. **Claude outputs нельзя использовать для обучения других моделей по условиям, указанным в источнике.** Этот проект выполняет анализ, не обучение генеративной модели.

Собственный программный код — MIT (`LICENSE`). Данные и выдержки не перелицензируются: применяются условия их источников (`DATA_SOURCES.md`, `data/raw/LICENSE`). Полные сторонние статьи, системные карточки и PDF исключены; оставлены ссылки, метаданные, короткие выдержки и проверки происхождения. Финальный DOCX с личным контактным блоком передаётся автору отдельно.

В статье использованы 14 рабочих источников с обозначением рецензируемых статей, препринтов и технических отчётов. Инвентаризация 30 исходных ссылок ТЗ сохранена в `data/literature/references.json`; это не требование цитировать все их в статье. Старые вспомогательные функции отбора/статистики сохранены для тестов и истории, но основной расчёт запускается через `review_revision.py`, без лимита 20 вопросов и без анализа correctness. `config.json` нужен вспомогательным модулям; дизайн версии 2 задаёт `review_config.json`.

`REVIEW_RESPONSE.md` сопоставляет все разделы рецензии с изменениями и явно отмечает оставшуюся независимую проверку разметки.
